![License](https://img.shields.io/badge/license-MIT-lightgrey)

Десктопное приложение для умной сортировки файлов с помощью **локальной**
нейросети (Ollama). Всё обрабатывается на вашем компьютере — ничего не
уходит в интернет, что важно для рабочих документов под NDA.

Работает **только по кнопке**, без фоновых процессов — не нагружает ПК.

## Возможности

- 📄 **Умная сортировка документов** — локальный ИИ читает PDF/Word/txt,
  определяет тип, компанию, дату и раскладывает по папкам.
- 🎬 **Распознавание типов файлов** — видео, таблицы, аудио, архивы,
  программы и др. раскладываются по категории и году без ИИ.
- 🖼 **Разбор фотографий** — по дате съёмки из EXIF (год/месяц), скриншоты
  отдельно.
- ✏️ **Правка перед применением** — поправить папку/имя у одного файла или
  сразу отправить группу отмеченных файлов в общую папку.
- 🔍 **Поиск** по всему складу с открытием файла/папки в проводнике.
- ↩️ **История и отмена (Undo)** — любую операцию можно откатить.
- 🛡 **Защита от дублей** — сравнение по содержимому (SHA-256), нормализация
  названий компаний, безопасный режим `move`.

## Технологии

`Python 3.10+` · `CustomTkinter` (GUI) · `Ollama` + `qwen2.5:3b` (локальный
LLM) · `pdfplumber` / `python-docx` (парсинг документов) · `Pillow` (EXIF) ·
`requests` (HTTP) · `pytest` (тесты) · `ruff` (линтинг). Многопоточность
(`threading`) для отзывчивого интерфейса, `dataclasses`, аннотации типов.

## Вкладка «Файлы» (готово)

Разбирает **любые** файлы из папки «Загрузки» по двум сценариям:

**Документы** (PDF, DOCX, DOC, TXT, MD, RTF) — локальная модель читает
содержимое и определяет: рабочий это документ или личный, тип
(Акт / Счёт / Договор / Заметка…), компании-контрагенты, дату, тему:
- рабочее → `Рабочее/<Тип>/<ГГГГ-ММ>/<Компания>/`
- личное → `Личное/<Тема>/`

**Остальные типы** — раскладываются по категории и году **без ИИ**
(быстро, не грузит модель): `<Склад>/<Категория>/<Год>/`. Распознаются:

| Категория | Примеры расширений |
|-----------|--------------------|
| Таблицы | xlsx, xls, csv, ods |
| Презентации | pptx, ppt, odp |
| Видео | mp4, mkv, avi, mov, webm |
| Аудио | mp3, wav, flac, m4a |
| Изображения | jpg, png, gif, svg, heic |
| Архивы | zip, rar, 7z, tar |
| Программы | exe, msi, apk, dmg |
| Код | py, js, html, json, sql |
| Книги | epub, fb2, mobi, djvu |

Неизвестные расширения → `Прочее/<Год>/`.

Работа всегда через **предпросмотр**: видно, что и куда переедет, можно
снять галочки с ненужного перед применением. Кнопка «✎» на строке правит
папку/имя одного файла, а «Изменить отмеченные» — сразу у всей группы.

## Поиск и История

- Вкладка **Поиск** — ищет по всем папкам склада по части имени с фильтром
  по категории; открывает файл или его папку в проводнике.
- Вкладка **История** — список последних операций с кнопкой **«Отменить»**:
  перемещённые файлы возвращаются на место, копии удаляются. Ключевая защита
  при работе в режиме `move`.

## Установка

### 1. Python-зависимости
```bash
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Ollama (локальная нейросеть)
Уже установлен. Нужно запустить сервер и скачать модель:
```bash
ollama serve
```
В отдельном окне (один раз):
```bash
ollama pull qwen2.5:3b
```
Модель `qwen2.5:3b` — лёгкая (~2 ГБ), хорошо понимает русский и работает
на процессоре без видеокарты.

### 3. Запуск приложения
```bash
.venv\Scripts\python.exe main.py
```

## Как пользоваться

1. Вкладка **Настройки** — укажи папку для сканирования и папки назначения,
   выбери `copy` (безопасно, копирует) или `move` (перемещает). Сохрани.
2. Вкладка **Документы** — «Проверить Ollama», затем «Сканировать папку».
3. Проверь предпросмотр, сними галочки с ненужного, нажми
   «Применить отмеченные».

> Совет: начни с режима `copy`, чтобы убедиться в качестве раскладки, и
> только потом переключайся на `move`.

## OCR для сканов (опционально)

Чтобы распознавать текст на сканах и фото документов, установи
[Tesseract-OCR](https://github.com/UB-Mannheim/tesseract/wiki) (с русским
языком) и раскомментируй `pytesseract` и `Pillow` в `requirements.txt`.

## Модуль 2: Фото (готов)

Вкладка **Фото** раскладывает фотографии по дате съёмки:

1. Указываешь папку с фото (можно **внешний диск**, напр. `E:\DCIM`) и куда
   раскладывать (напр. `D:\Фото`). Настройки можно менять в любой момент.
2. Дата берётся из **EXIF** (тег DateTimeOriginal), а если его нет
   (скачанные картинки, скриншоты) — из даты изменения файла.
3. Результат: `<Куда>/<Год>/<ММ_Месяц>/` — например `2017/04_Апрель/`.
4. Скриншоты (по желанию) уезжают в отдельную `Скриншоты/<Год>/`.
5. Итог показывается **сгруппированно** по годам/месяцам с количеством фото —
   отмечаешь нужные группы галочками и жмёшь «Применить».

> Про диски: назначение можно указать на диск `D:` или внешний накопитель —
> подпапки создаются автоматически. У внешних дисков буква может меняться
> (сегодня `E:`, завтра `F:`) — если диск отключён, приложение не падает,
> а показывает ошибку по конкретному файлу.

## Перенос файлов и защита от дублей

- Режим **`move`** удаляет файл из «Загрузок» только после успешного переноса.
  Если возникла ошибка — файл остаётся на месте.
- **Дедупликация по содержимому** (размер + SHA-256): одинаковый файл не
  копируется повторно при новых сканированиях. В режиме `move` лишний
  оригинал убирается из «Загрузок».
- **Нормализация названий**: `ООО «Ромашка»` и `Ромашка` попадают в одну
  папку; типы документов приводятся к единому списку — папки не задваиваются.

## Разовая чистка склада от старых дублей

Если дубли уже накопились (например, после работы в режиме `copy`):

```bash
python tools/cleanup_sklad.py "D:/Sklad"          # показать план (ничего не меняет)
python tools/cleanup_sklad.py "D:/Sklad" --apply  # выполнить
```

Утилита сливает папки-двойники и убирает файлы с одинаковым содержимым.
Дубликаты не удаляются насовсем — перемещаются в папку `_Дубликаты_<дата>`
внутри склада; проверь их и удали вручную.
